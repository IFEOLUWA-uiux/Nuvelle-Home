# Nuvelle Home

Furniture e-commerce platform created for a United States home-furnishings store.

[View the live site](https://nuvellehome.netlify.app)

## What this project includes

- Editorial storefront and product-discovery journeys
- Category browsing, product pages, cart, and checkout flows
- Search, filtering, and responsive shopping interfaces
- Customer-facing pages alongside admin-facing management surfaces
- Image-led product presentation for desktop and mobile customers

## Built with

HTML, CSS, and JavaScript

## Run locally

Open `index.html` in a browser, or serve the repository with any static-file server.

## Notes

This repository contains the storefront source and supporting project assets.
